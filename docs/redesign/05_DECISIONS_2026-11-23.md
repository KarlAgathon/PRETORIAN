# PRETORIAN / Media Center — Redesign decisions (23.11.2026)

Owner's decisions on the seven technical conflicts raised after the SERIES specification (04_SERIES_SPEC.md).
These clarifications are part of the master specification (01–04) and take precedence over them where they differ.

1. **Playback Speed** — approved for MOVIES and SERIES only. Not for Live TV.
2. **Skip Intro** — never guess an intro length and never jump ~85 s. Keep the existing learning infrastructure and any reliable saved intro markers. Show Skip Intro only when valid timing exists. Manual intro-marker configuration may be added later.
3. **Episode thumbnails** — approved. No episode image → clean, neutral, non-blurred fallback with the episode number. Never empty blurred boxes.
4. **Four settings icons** — Single Series View: Subtitles, Audio, Playback, Picture in the right-side area above the episode carousel. Fullscreen playback: the approved MOVIES player layout. All four floating menus expand upward.
5. **Watched / Unwatched** — approved. Show only the contextually relevant action. Keep the small checkmark and the thin white episode progress bar.
6. **Trailer** — always the original red YouTube Play logo, in MOVIES and SERIES.
7. **Online subtitles** — reuse existing integrations. Before implementation verify the available providers, API-key requirements, rate limits and episode matching.
8. **Weather** — Open-Meteo, location chosen in Settings. No hard-coded city.

**Implementation sequence** — accepted as proposed:
1. Design foundation (tokens, concrete background, watermark, shared upward floating menu)
2. Shared poster gallery for Movies and Series
3. Single Movie View with the four menus
4. Single Series View (episode carousel with wrap, season selector, long-OK overlay, watched states)
5. Player (paused overlay, Down = four icons, speed, Auto Next 10 s)
6. Home screen
7. Translations, clean-up, final check

**Mandatory navigation contract (everywhere): ONE MENU — ONE LEVEL — COMPLETE REPLACEMENT.**
Applies to every MOVIES and SERIES category: Recently Added, Continue Watching, My List, Favorites, Genres, Provider Groups and Search Results.
Opening a category completely replaces the previous menu with its poster gallery.
BACK returns exactly one logical step and restores the previous focus and scroll position, all the way back to HOME.
No extra navigation levels; no previous menu left visible.

**Status:** documentation only. No implementation until the owner's explicit authorization.
