# PRETORIAN

Modern IPTV player for Android TV (Google TV Streamer, Mi Box).

**v0.1** – Xtream Codes and M3U playlists, live TV by groups with favorites, movies and series (Xtream), full-screen player (Media3) with channel zapping, external player, trailer search.

Next: EPG guide, Stalker portal, TMDB/IMDb metadata, online subtitles, profiles, simple mode with PIN, Sports Center.

APK: see [Releases](../../releases/latest). Built and signed by GitHub Actions.
